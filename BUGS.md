# Найденные дефекты API

**Окружение для всех дефектов:** [qa-internship.avito.com](https://qa-internship.avito.com), Windows, Python 3.13.3, pytest 9.2.0.

**Подготовка:** зарегистрировать нового пользователя, получить JWT; выполнять запросы с его Bearer-токеном и использовать собственные объявления.

Всего пройдено тестов **38** : **34 passed, 4 failed**. 

## BUG-01 — Коды ошибки статистики v2 не совпадают (API-20)

- **Шаги:** отправить `GET /api/2/statistic/not-a-uuid`.
- **Факт:** HTTP `404`, но JSON `status` отличается от `404`.
- **Ожидание:** при HTTP `404` значение JSON `status` также равно `404` после приведения к строке.
- **Серьёзность:** S1 Minor.

## BUG-02 — Коды ошибки повторного удаления не совпадают (API-22)

- **Шаги:** создать объявление; удалить через `DELETE /api/2/item/{id}` (`200`); подтвердить отсутствие через GET (`404`); повторить DELETE.
- **Факт:** HTTP `404`, но в теле ответа  `"status": "500"`.
- **Ожидание:** при HTTP `404` значение JSON `status` также равно `404` после приведения к строке.
- **Серьёзность:** S1 Minor.

## BUG-03 — Статистика удалённого объявления доступна после удаления (API-31, API-32)

- **Шаги:** повторить для `v=1` и `v=2`: создать объявление; получить статистику (`200`); удалить объявление (`200`); подтвердить `GET /api/1/item/{id}` → `404`; запросить `GET /api/{v}/statistic/{id}`.
- **Факт:** обе версии статистики возвращают HTTP `200` после подтверждённого удаления.
- **Ожидание:** HTTP `404`, статистика недоступна — согласно API-31/API-32.
- **Серьёзность:** S2 Major.
